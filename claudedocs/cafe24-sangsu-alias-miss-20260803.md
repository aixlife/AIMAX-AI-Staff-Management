## 3. 원인

카페24 상품명 → 직원 매칭 규칙에 직무명 **"경리"가 없다.**

```
{ product: "sangsu", priceWon: 9900, patterns: [/상수|sangsu|견적|견적서|quote|quotation|estimate/] }
```

쇼핑몰이 직원 상품을 별명으로 올리는 중이다:

| 상품명 | 매칭 여부 | 매칭시킨 단어 |
|--------|-----------|---------------|
| 오피스매니저 **존** | 성공 → 지은 | 오피스매니저 |
| 자료조사원 **조지** | 성공 → 송이 | 자료조사원 |
| 경리 **샘** | **실패** | (없음 — "경리"가 규칙에 빠짐) |

앞의 둘은 직무명이 규칙에 있어서 별명이 바뀌어도 살아남았고, 상수만 직무명이 빠져 있어 `unknown_product`로 떨어져 5일간 대기열에 묶였다.

**부수 위험**: needs_review 대기열 215건 중 213건이 강의·전자책 등 직원 상품이 아니다. 텔레그램 알림은 7/28에 정상 발송됐지만 노이즈에 묻혀 아무도 못 봤다. 특히 "스레드 가이드북 PREMIUM 전자책"은 7/31~8/3에도 계속 유입 중이다.
