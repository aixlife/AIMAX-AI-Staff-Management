## AIMAX 입점 업무협약서 — 훔쳐봐

주식회사 메이크패밀리(이하 "갑")와 정보람(훔쳐봐 운영자, 이하 "을")은 을이 운영하는 AI 레퍼런스 수집 서비스 "훔쳐봐"(hoomcha.com)의 AIMAX 입점·판매 협력에 관해 다음과 같이 합의한다.

1. (대상) 을의 서비스 "훔쳐봐" — 라이트 월 19,900원 / 프로 월 29,900원 구독 상품.
2. (역할) 을은 제품의 소유자·운영자로서 운영, 유지보수, 장애 대응, API 비용, 고객 데이터 관리, 환불 처리를 담당한다. 갑은 AIMAX 입점 페이지 등록, 커뮤니티·채널 소개, 판매 연결, 1차 문의 정리를 담당한다.
3. (유입 구분) 갑 경유 고객은 전용 페이지(hoomcha.com/aimax)로 유입되며, 을의 관리페이지에서 갑 경유 가입·결제만 분리 집계한다.
4. (수익쉐어) 갑 경유 고객의 결제 총매출 기준 **을 60% / 갑 40%**. [제안] 구독 갱신 결제도 최초 유입 경로를 따른다.
5. (정산) [제안] 매월 말일 집계, 익월 10일까지 을이 갑 몫을 지급하고 판매 리포트를 공유한다.
6. (환불) 환불 발생 시 해당 건은 정산에서 차감하고, 이미 정산됐다면 다음 정산에서 조정한다.
7. (기간·해지) [제안] 협약 기간 1년, 만료 30일 전 서면(메시지) 통보 없으면 자동 연장. 양측 모두 30일 전 통보로 해지 가능하며, 해지 시 기발생 정산 의무는 유지된다.
8. (기타) 본 협약에 없는 사항은 상호 협의로 정하며, 실제 분쟁 대비 정식 계약서가 필요해지면 법무 검토를 거쳐 대체한다.
