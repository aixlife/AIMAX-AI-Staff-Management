# 예리 네이버 블로그 템플릿 재설계 — 초안

작성 2026-08-26 · 근거: 상위 노출 글 46편 실측 + 우리 원고 320편 전수 + 네이버 공식 문서 41페이지 + 가독성 연구

---

## 결정 박스

**질문**: 예리 글 템플릿을 이 초안대로 바꿀까?

**추천**: 바꾼다. 단 프롬프트 교체(A)와 실행기 꾸미기 기능(B)을 분리해 A부터.

**근거 3**
1. 우리가 따르던 "1,500자·이미지 3장" 공식은 **네이버 기준이 아니다.** 서치어드바이저 가이드 41페이지 전수 검색 결과 본문 분량 기준은 0건이고, 숫자 규칙은 사이트 제목 40자·설명 80자뿐이다.
2. 분량은 이미 맞다(우리 1,518자 vs 상위글 1,624자). **틀린 건 덩어리 크기다** — 우리 한 문단 122자, 상위글 11자.
3. **볼드를 안 쓴 상위글은 46편 중 0편이다.** 우리는 볼드가 코드로 꺼져 있어 0개다.

**반대 근거**: 상위 노출과 "읽히는 글"은 다른 목표다. 이 초안은 읽히는 쪽에 무게를 뒀고, 노출 성과는 A/B로 확인해야 한다. 성과 데이터(조회수·체류)는 우리에게 없다.

**승인하면**: 서버 생성 프롬프트를 종류별로 교체하고, 실행기에 볼드·정렬을 켠다.
**거절하면**: 지금 구조가 유지된다 — 122자 문단, 볼드 0.

## 2. 근거가 겹치는 규칙

- **덩어리는 짧게** — 상위글 실측 11자 · WCAG 2.2는 CJK 한 줄 40자를 접근성 상한으로 규정 · Yoast 임계값 한국어 환산 문단 상한 315자(우리 최대 377자는 이마저 초과)
- **결론은 3번째 덩어리 안에** — NN/g 아이트래킹 150만 고정: 단락 열람률 1번째 81% → 2번째 71% → 3번째 63% → **4번째 32%로 급락**
- **훅은 첫 화면 안에** — NN/g: 열람 시간의 57%가 첫 화면, 상단 20%에 42% · 모바일 한 화면은 한국어 500~600자
- **15초 게이트** — Chartbeat 20억 방문: 55%가 15초 미만 체류
- **볼드는 스캔의 착지점** — NN/g F패턴/레이어케이크: 독자는 훑다가 굵은 곳에 내려앉는다. 상위글 46/46이 사용
- **소제목 간격** — Reuters 200~250단어마다(한국어 420~525자) · Semrush 120만 아티클: h2 없는 글은 39%가 저성과

## 4. 글 종류별 템플릿

### 비교형 (A vs B, 무엇을 고를까)
```
훅  독자가 지금 겪는 판단 문제 1~2줄
결론  "이런 사람은 A, 이런 사람은 B" — 3번째 덩어리 안
## 무엇이 다른가        핵심 차이 3가지, 각 2~3줄
## 나는 어느 쪽인가      기준 3~4개를 목록으로
[이미지]
## 이럴 땐 반대로 본다    예외 상황
## 오늘 확인할 것 하나
```

### 방법형 (어떻게 하나)
```
훅  안 될 때 벌어지는 일 1~2줄
결론  전체 절차를 한 줄로 요약 — 3번째 덩어리 안
## 준비물
## 순서                  번호 목록, 한 단계 한 줄
[이미지 — 각 고비마다]
## 자주 막히는 지점
## 이것만 지키면 된다
```

### 후기형 (써봤다)
```
훅  사기 전 내 고민 1~2줄
결론  지금 만족하는지 — 3번째 덩어리 안
## 왜 이걸 골랐나
## 실제로 써보니          구체 수치·기간
[이미지 — 실물]
## 아쉬운 점             반드시 넣는다
## 누구에게 권할까
```

### 정보형 (알아두면 좋은 것)
```
훅  모르면 손해 보는 지점 1~2줄
결론  핵심 사실 한 줄 — 3번째 덩어리 안

```

## 5. 실행 순서

**A. 서버 생성 프롬프트 (즉시 가능, 실행기 배포 불필요)**
- 종류별 뼈대를 프롬프트로 분기
- 덩어리 40자 상한, 결론 3번째 안, 소제목 400~500자 간격 지시 추가
- 볼드 표시(`**`)를 1,000자당 8~10개, 어절 단위로 넣게 지시
- 지금 프롬프트에 없는 것: 문단 길이·결론 위치·읽는 호흡 — 지시 0개였다

**B. 실행기 (빌드·배포 필요)**
- 볼드를 기본 켜기 — `AIMAX_EDITOR_ENABLE_BOLD` 기본값을 켬으로 바꾼다
- 문단을 40자 단위로 끊어 입력(현재는 마크다운 문단 하나를 통으로 입력)
- 인용구·가운데 정렬 사용
- 색상은 강조 한 색만 옵션으로

**C. 검증**
- 새 템플릿으로 5편, 옛 템플릿으로 5편 생성해 같은 잣대로 계측
- 대리지표(임시저장 후 실제 발행 비율, 재생성 횟수)로 A/B — 이 지표는 지금처럼 구조가 균질할 때는 못 쓰지만, 두 템플릿이 갈리면 유효해진다

## 6. 확인 못 한 것

- **성과 데이터 없음** — 조회수·체류시간은 사용자 네이버 계정에 있고 우리 서버엔 없다. 이 초안은 "읽히는 구조"의 근거이지 "상위 노출 보장"이 아니다
- 상위글 46편은 정보성 키워드 8개 기준이다. 상업성·리뷰 키워드는 다를 수 있다
- "한 덩어리 11자"는 네이버 에디터가 줄마다 문단 태그를 만들어 나온 값이다. 사람이 의도한 문단 단위와는 다를 수 있어, 실제 눈에 보이는 덩어리 기준으로는 40자 상한을 권한다
- 우리 320편의 "문단 122자"는 마크다운 기준이고, 렌더 후 실제 화면에서도 한 덩어리로 붙는지는 발행 글 1편으로만 확인했다(스크린샷)
