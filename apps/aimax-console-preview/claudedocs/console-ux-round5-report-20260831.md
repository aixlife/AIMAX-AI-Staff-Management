## 구현 6건

1. **작성 모드 3단 (예리·윤미 공통)** — 글쓰기 모델 select(6종)를 카드 3장으로 교체.
   표준=Gemini 3.7 Flash($0.75/$3.75, 기본값) · 균형=GPT-5.6 Terra($2.00/$12.00) ·
   프리미엄=Claude Sonnet 5($3.00/$15.00). 각 카드에 모드명 + 실제 모델명·단가 보조
   표기 + 성격 한 줄. 예상 비용 박스는 모드 기준으로 갱신. 이미지 모델 select는 유지.
2. **카테고리 조건부** — 예리 기본 화면에서 제거, 발행 방식이 즉시·예약 발행일 때만
   고급 설정 안 "발행할 네이버 게시판"으로 노출 + 도움말 "비워두면 기본 게시판에
   발행됩니다". 임시 저장(기본값)에서는 숨김, 값은 보존.
3. **스타일 템플릿 미니 와이어프레임** — SVG 스켈레톤(TemplateWireframe): 상담
   유도형=본문 블록+하단 강조 CTA 배너, 정보 정리형=목차 박스+불릿, 후기
   추천형=전후 비교 프레임+평점 카드. 계정 기본 카드는 현행 유지(그림 없음),
   "예시 보기" 토글 유지.
4. **최근 설정 불러오기 칩 (4개 폼 직원 공통)** — 업무 생성 시 폼 설정을
   sessionStorage에 저장(lib/recentSettings.ts). 폼은 항상 기본값으로 열리고 저장분이
   있으면 상단 칩만 노출, 클릭 시에만 복원(자동 복원 금지). 파일 항목 제외,
   선택지에 없는 값·깨진 JSON은 무시.
5. **상수 즉시형 예외** — "견적서 생성하기"가 업무 페이지로 이동하지 않고 그 자리에서
   완성 견적서(QuotePreview 문서 스타일)를 열고 다운로드 버튼 제공
   (lib/quoteDocument.ts). 업무 페이지에는 완료 상태로 조용히 적재(이동·강조·토스트
   없음), 결과 화면에 "업무 기록에서 보기" 링크만. 예리·현주·윤미는 현행 이동+강조 유지.
6. **윤미 유료 전환 위치** — 폼 비용 박스에 "기본 초안은 무료입니다 · AI 완성 전환은
   결과 확인 후 선택" 명시(설명 없는 0원 금지). 폼에는 전환 선택 없음(모드만 선택).
   업무 페이지의 윤미 완료·확인 필요 화면에 "AI로 완성하기 · 예상 ₩14" CTA →
   모드별 예상 비용(₩14/₩44/₩56) + "실서비스에서는 이 시점에 과금 확인" 고지
   픽스처 다이얼로그(실동작 없음). 확인 필요 픽스처 비용 문구도 표준 모드로 정렬.
